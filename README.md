# Lab 2: Events in Motion

## Project

**Mood Playground** is a simple interactive webpage made with HTML, CSS, and JavaScript.

## Required interactions demonstrated

- **Pointer event:** moving the mouse or a finger inside the activity box moves the small dot and updates its coordinates.
- **Click/touch event:** clicking the circle changes its size, click counter, and status message.
- **Keyboard event:** number keys `1–4` change the page mood, colours, active button, and status message.
- **Keyboard/button event:** the Space key or Pause button pauses and resumes the clock.
- **Window event:** resizing the browser updates the displayed window dimensions.
- **Time event:** `setInterval()` updates the clock once per second.

## Technical focus

- DOM selection and manipulation
- Event listeners
- CSS classes and data attributes controlled with JavaScript
- Browser Object Model: `window.innerWidth`, `window.innerHeight`, and `setInterval()`
- Responsive layout for desktop and mobile
