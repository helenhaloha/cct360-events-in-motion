# Lab 2: Events in Motion

## Project

**Weather Within** is an interactive single-page interface that responds to the user through multiple browser events.

## Required interactions demonstrated

1. **Pointer event:** moving the mouse or pointer changes the light position, coordinates, and orb angle.
2. **Click/touch event:** pressing the orb creates animated signal particles, updates the signal counter, and changes the live event message.
3. **Keyboard event:** number keys `1–4` change the entire atmosphere, including color, text, and readings.
4. **Keyboard/button event:** the space bar or Space button pauses and resumes the clock and animations.
5. **Window event:** resizing the browser updates the live viewport measurement.
6. **Time event:** `setInterval()` updates the clock every second.

## Technical focus

- DOM selection and manipulation
- Event listeners
- Dynamic element creation and removal
- CSS custom properties controlled by JavaScript
- Browser Object Model: `window.innerWidth`, `window.innerHeight`, `setInterval`, `navigator.vibrate`
- Keyboard, pointer, click, touch-compatible, resize, and time events

Open `index.html` in a browser to view the project.
